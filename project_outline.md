# Estructura DigitalVerse - Árbol de Archivos

## Archivos Principales
- **index.html** - Página de inicio con banner y destacados
- **catalogo.html** - Catálogo completo con filtros
- **producto.html** - Vista individual de producto
- **planes.html** - Suscripciones y precios
- **generador.html** - Generador IA de tarjetas
- **login.html** - Registro y login de usuarios
- **panel.html** - Panel de usuario
- **admin.html** - Panel de administración
- **legal.html** - Políticas y términos legales

## Recursos
- **main.js** - Lógica principal y navegación
- **admin.js** - Funciones de administración
- **generador.js** - Motor de generación IA
- **productos.json** - Base de datos de productos
- **usuarios.json** - Datos de usuarios (simulado)
- **imagenes/** - Carpeta de recursos visuales

## Librerías Externas
- Anime.js - Animaciones y transiciones
- ECharts.js - Gráficos de estadísticas
- Splide.js - Carruseles de productos
- p5.js - Efectos visuales de fondo
- Pixi.js - Efectos de partículas
- Glfx.js - Procesamiento de imágenes

## Características Implementadas
- Sistema de carrito de compras
- Filtros avanzados por categoría
- Búsqueda en tiempo real
- Validación de formularios
- Gestión de usuarios
- Sistema de promociones
- Generador automático IA
- Panel de estadísticas
- Cumplimiento legal español
